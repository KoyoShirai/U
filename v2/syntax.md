# 文法

### 単語の生成

| | C | 'C | V |
| :---: | :---: | :---: | :---: |
| 0 | η/3 | h | ε/u |
| 1 | p | b | a |
| 2 | t | d | e |
| 3 | k | g | i |
| 4 | q | j | o |
| 5 | f | v | u' |
| 6 | s | z | a' |
| 7 | x | c | e' |
| 8 | m | n | i' |
| 9 | l | r | o' |

以下の規則によって自然数と単語を対応させる。

例1 80910230  
例2 0

例1 ...000080910230  
例2 ...000000000000

1. 右から順にC列、V列に交互に対応させる

例1 ...εηεηi'ηo'pεtiη  
例2 ...εηεηεηεηεηεη

2. 右から2ケタ目がεならuにする

例1 ...εηεηi'ηo'pεtiη  
例2 ...εηεηεηεηεηuη

3. 一番左のεでもηでもない文字より左にある文字をすべて消す

例1 i'ηo'pεtiη  
例2 uη

4. εをuにする

例1 i'ηo'putiη  
例2 uη

5. 左に ' がある子音を'C列のものに変える

例1 ihobutiη  
例2 uη

6. ηを消す

例1 ihobuti  
例2 u



### 動詞

語頭の子音がC列(子音無しも含む)の動詞は自動詞であり、'C列の単語は他動詞である。
